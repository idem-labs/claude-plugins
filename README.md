# idem-labs / claude-plugins

Claude Code plugin marketplace for [idem-labs](https://github.com/idem-labs).

## Install this marketplace

```
/plugin marketplace add idem-labs/claude-plugins
```

## Available plugins

| Plugin | Description |
| --- | --- |
| [super-compass](https://github.com/idem-labs/super-compass) | Opinionated project governance framework: CLAUDE.md + PROGRESS/ROADMAP/CHANGELOG/ARCHITECTURE docs + ADRs + lessons + knowledge base + session rituals as slash commands. |

## Install a plugin

```
/plugin install super-compass@idem-labs
```

## Updating

```
/plugin marketplace update idem-labs
```
